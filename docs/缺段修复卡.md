## 一、路径（甲乙互斥，只启一条）

**选定：甲路径（唯一启用）**

- 任一分段缺失或为空 ⇒ 整笔拒映，正式区零增；拒映记录落库可查。
- 齐套核证以部件账为唯一事实源，不得信任"齐全"徽章字段。
- 乙路径（允许主段出键 + 同事务写缺段标记 + 把该类剔出齐套桶）**当日不启用**，不得与甲混用；任何 `path=乙` 的请求按偏离拒写。

## 二、五处同态

以下五处对同一批次必须同态，写入后即时核对，不同态则整笔回滚：

1. 部件账 `parts_ledger`
2. 正式实体 `formal_entities`（按 `batch_id` 关联）
3. 互证桶 `attest_buckets`
4. 装载列表 `ingest_batches`
5. 重映回执 `remap_receipts`

口径：

- 齐套且已重映 ⇔ 五处齐全（正式实体 / 互证桶 / 重映回执三者同在）
- 缺段 ⇔ 部件账缺任一段 ⇔ 无正式实体、无互证桶、无重映回执
- 只改徽章（直接把 `status` 改成齐全/齐套）而不补段 ⇒ 判偏离

## 三、并发与偏离

- 补段与重映必须持有 **ingest 锁**（`ingest_locks`，按 `batch_id`，非阻塞抢锁）。
- 后到者只记争用（`ingest_contentions`），不改五处任何状态，返回 423。
- 偏离修复卡（`force=true`、`path=乙`、徽章与部件账不符）⇒ 拒写并记 `缺段偏了`。
